# Validation / Phase 7
Zig 0.17.0 / macOS Apple Silicon。Debug build + tests、ReleaseSafe build/tests、Linux x86_64 musl CLI cross-build、mimoc-ui test + check-embedded成功。DSPの周波数精度、倍音比(DFT)、continuous phase、block独立、60秒連続、envelope/release/silence、gain/境界/NaN、C99 renderer比較、Morse PARIS(50単位)、FFT bin精度、SPSC容量/順序、callback live update/late detection、JSON strict roundtrip、GUI handler slider/numeric/key/Undo/A-Bをテスト。
`tools/verify_pcm.py` は独立した元ファームウェアC++ headerとC99 adapterをコンパイルし、WAVヘッダー/sample数/silence/peak/RMS/clipを検証。詳細はpcm-verification.json。現ホストではC99のPCM差0 LSB、legacy定常区間差0 LSB。全区間の最大差7340 LSBはlegacy one-shotが終了前にrelease、Studioがkey-up後にreleaseする設計差。attack divisorもNとN-1が異なる。
GUI実操作: .app起動、CoreAudio初期化、Space再生/停止、450→600Hz直接入力、周波数dragで881.818Hzへ更新、JSON保存、Baselineへ切替後JSON読込で復元を確認。読込操作中に自動操作APIがタイムアウトしたがEscape後の画面でPRESET LOADEDと881.818Hzの復元を確認。monitor dropはmodal panel中にUIがconsumerを停止するため増えるが音声生成には影響しない。確認時のLATE=0/CLIPS=0。聴覚評価なし。
未検証: ESP32-S3上のCPU/メモリ/音響/I2S、CH32実ボード、デバイス変更/48kHz実デバイス、長時間の実音声stress、GitHub CI実行。check-embeddedはRV32 freestanding smokeでCH32 firmware全体buildではない。最終.appでSOS再生中の450→600Hz入力、PCM/FFTの更新、Space停止、native zoomによるサイズ変更後の描画を確認。SoftFm/SynthBeep/BrightFmの完全再現は対象外で、Baselineはlegacy soft sine。
